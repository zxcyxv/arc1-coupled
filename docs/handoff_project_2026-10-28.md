### 1.4 학습된 가소성 창 (`scripts/analysis/plasticity_window.py`)

- K₊(Δ) = Σ_r γ_r Re(a_r z_r^Δ)(pre 선행), K₋(Δ) = Σ_r γ_r Re(b_r z_r^Δ)(post 선행), 같은 블록 Hebb 항 +1 기준의 상대값.
- 스도쿠 bands 16블록 43,325스텝(이전 레포 체크포인트, sha 확인): 헤드 2 인과 쪽 강화(넓이 +1.86 / −0.08, 고전 STDP에 가장
  가까움), 헤드 0·3 뒤집힌 STDP(−0.91/+0.35, −1.29/+0.84), 헤드 1·4·5·7 양쪽 anti-Hebbian, 헤드 6 거의 0. η는 대부분 상한 0.125.
- ARC: ≤10 1D는 양쪽 anti-Hebbian(인과 쪽이 강함), ARC-1 16/10은 진동형, ARC-2 1D는 짧은 시차 양쪽 강화·시차 3~6 억압(멕시코 모자형).

## 2. 함의

1. 시범을 문맥으로 읽는 이 구조는 작은 격자에서 경쟁력이 있다(같은 하네스에서 TRM 구조의 약 4배). 하지만 ARC-2 규칙은
   현재 가설 족 밖이고, 시범 쌍조차 맞히지 못한다. 실패는 λ, wd 범위, 위치 주파수, 격자 크기만의 문제가 아니다.
2. ≤10의 상한은 학습 쌍 877개에서의 일반화가 정한다(holdout). 세부 설정(wd, frame_omega, λ)은 상한을 몇 개만 움직였고,
   구조(30/10 + 출력 FFN)가 약 +10~15를 줬다(블록 수와 FFN의 몫은 미분리). 그리고 이 구조에서는 상한이 막히지 않는다:
   20만 스텝까지 1만 스텝당 약 1개씩 직선에 가깝게 오른다. 같은 구조로 ARC-1 전체 런을 다시 돌릴 근거다(기존 전체 런은
   학습 2D RoPE로 7천 에폭부터 view 0.150에서 막혔다). 예상: 4×H100(시간당 $6.94)에서 약 0.92 s/step, 5천 에폭 약 6.6시간
   약 $46~50, 1만 에폭 약 $92~100. 결정은 사용자(GPU 작업은 10-28에 종료).
3. 학습되는 위치 코드는 외우기 쪽으로 간다(학습 2D RoPE). 고정하면 관례(TRM의 1D RoPE)와 같아진다. 사용자 판단으로 논문의
   Theory에는 넣지 않는다.
4. 시험 CE 상승은 상한 판단에 쓰면 안 된다. CE는 6~8천 스텝에 바닥을 찍고 오르지만 정답 수는 2만 스텝 넘게 계속 오른다.
   상한은 같은 길이로 돌린 뒤 평가 여러 번의 구간 평균으로 비교한다(평가 한 번은 ±3~5).

## 3. 논문 (10-28 합의)

### 3.1 주 논지 (Theory, Novelty): 재귀의 시간축과 STDP

- 형식화된 Hebbian 규칙(Δw = η·pre·post)에는 시간이 없다. Hebb(1949)의 원문("takes part in firing it")은 인과적이었고, STDP가
  형식화에서 빠진 순서를 되살렸다.
- Hebbian → fast weight → linear attention 계보는 시간 없는 형식을 물려받았다. 재귀 transformer(HRM, TRM, URM)는 재귀라는
  시간축을 만들었지만 그 축을 가로지르는 기억이 없다(단계마다 attention을 새로 만든다). Hebbian은 정의상 시간에 따라 누적하는
  규칙이 아니므로, "Hebbian을 재귀에 누적하는" 대조군은 필요 없다(사용자). 비교 대상은 TRM이다.
- 비대칭 커널은 서로 다른 시각의 짝을 적분한다. 홀수 성분은 고정점에서 0이라 도착점이 아니라 궤적을 기억한다. 직류 성분이
  Hebbian 항이라 STDP는 Hebbian의 일반화다(Kempter 1999 분해).
- 같은 시각 kv 항(토닉 항)은 이론이 아니라 구현 세부다: 없으면 학습되는 커널만으로는 스케일이 작다(창 넓이를 1로 초기화해도).

### 3.2 둘째 논지 (Novelty, Universality): TEM / TEM-t의 구조·내용 분리를 ARC에

- 공유 가중치가 구조 코드 φ를, 과제별 결합은 시범에서 푼 θ(S = Σ y φᵀ: Hebbian, θG: 탈상관, 연화 문턱: 희소)에 둔다. 프레임 항은
  위치 key → 색 value 인출(TEM-t). 시범 → 질의 경로는 규칙 헤드뿐(명제 4).
- 찾은 범위에서 TEM 계열을 ARC에 적용한 선례는 없다. HRM은 관련 연구에서 TEM을 소개만 했고 HRM의 영감은 위계·다중 시간척도다
  (ARC Prize 분석: 위계 자체의 몫은 작음). MapFormer(arXiv 2511.19279)가 TEM-t를 일반화한 가장 가까운 연구. "To our knowledge"를 붙인다.
- 영감의 서술은 실제 설계 경위에 맞춘다(사용자는 TEM, TEM-t를 염두에 두고 설계했다).

### 3.3 뺀 것

- RoPE 1D 발견(관례로 돌아간 것), holdout·외우기(HRM~URM에서 알려진 것), ARC-2 정량 진단은 Theory에서 뺀다(사용자 결정).
  다만 ARC-2 0%는 주 결과표에 넣는다(트랙이 ARC-AGI-2).

### 3.4 용어

- 새 용어를 만들지 않는다. "TDP", "희소 LTD"는 이전 레포의 내부 용어였다.
- "eligibility trace를 가진 temporally asymmetric Hebbian 규칙, 커널은 학습(STDP-like)". 활동은 부호 있는 집단 부호라 LTP/LTD는
  원소 변화의 부호가 아니다. "LTP-like / LTD-like lobe"를 연합 v kᵀ 쪽으로 / 반대쪽으로 옮기는 것으로 정의하고 쓴다.
- lasso의 연화 문턱은 "soft-thresholding(proximal ℓ1, ISTA)", 신경 해석이 필요하면 LCA(Rozell 2008). 부호 있는 Hebbian의 전례:
  공분산 규칙(Sejnowski 1977), fast weight(Schmidhuber, Ba 2016, Schlag 2021). 모두 서지 확인 필요.

### 3.5 결과표와 그림 계획

- 표 1(주 결과): ARC-1 eval pass@2 0.1875, ARC-2 0/172, TRM 기준(ARC-1 0.418 우리 평가, ARC-2 7.8% 논문).
- 표 2(같은 하네스 비교): TRM 구조 약 24 대 우리 약 119(20만 스텝 구간 평균; 같은 데이터·배치·loops 1, deep supervision 없음
  단서). 88쌍 참고 수치. 그림: ≤10 학습 곡선(`docs/figures/small_b30g10_wdmat_curve.png`, 포화 없음).
- 스도쿠: 정확도, 1만 블록 외삽(256블록 306 → 1만 블록 420, 오차 55.3% 감소, 재발 0, 못 푼 92문제 중 89개가 오답에 고정되지
  않고 떠돎), **TRM 스도쿠 체크포인트 외삽과의 오차 감소율 비교**(기록은 이전 레포에 있음; 같은 512문제·같은 정의인지 확인 후 사용).
- 창 모양 그림(스도쿠 헤드별, ARC), 창 분석은 각 한 줄: 고정점 Hebb 이득을 상쇄하는 헤드 수(M₀ −0.6~−0.96, 8헤드 중 7), 순서에
  따라 부호가 바뀌는 헤드.
- 추가 후보(GPU 필요): 스도쿠 외삽에서 문제별 위반 수 궤적으로 "풀리는 순간이 갑작스러운가"(유레카형) 측정.

### 3.6 한계와 다음 단계 절에 넣을 것

- ARC-2: 가설 족을 넓히는 원리적인 길(손 코딩 연산자 없이): 학습된 사전(원자) + lasso 선택, 재귀를 통한 생성자 합성(원환 토이:
  학습된 생성자 합성으로 처음 보는 변환 100%), 헤드별 규칙 시냅스(지각의 계산을 과제가 바꿈, 명제 4 유지).
- 헤드별 규칙 시냅스의 두 종류: 내용 헤드(φ → 관측 색, 정리 0이 헤드마다 성립), 전이 헤드(φ(t) → φ(t+1), 시범 궤적에서 푼 전이를
  질의에 적용: TEM 전이 가중치와 STDP가 한 헤드에서 만남). y가 반복 내내 상수면 비대칭 커널은 φ 필터일 뿐이라 순서가 표현되지 않는다.
- 3요소 규칙(eligibility × 내부 도파민 = 시범 정합성의 예측 오차)과 경쟁(WTA): 유레카(정합성의 도약)가 궤적을 굳히고, 정체가
  탐색을 넓힌다. 원환 토이 1단계 결과(별도 문서)와 Backpropamine(Miconi 2019) 대비 차이를 적는다.
- lasso와 STDP+WTA는 같은 경쟁 원리의 두 축(설명력 / 시간 선행)이고, L1 대 L0(연화 문턱 대 하드 문턱, ISTA 대 IHT)의 차이가 있다.
  지연 가중 lasso(λ_j = λ·f(지연_j))로 하나의 목적에 묶을 수 있다(아이디어).

## 4. 기제 (논문 본문용 요약)

- **bands 기억(헤드별):** E_K,r ← z_r E_K,r + γ_r k̃, D_V,r = z_r E_V,r, E_V,r ← D_V,r + γ_r v, S = Σ_r Re(a_r vᵀE_K,r + b_r D_V,rᵀk̃),
  W ← (1−η)W + ηS, read = q̃(Σ v k̃ᵀ + W)ᵀ. z_r = exp(−e^ν + iθ), γ_r = √(1−|z_r|²). 시간축은 블록(재귀 깊이). k̃, q̃는 단위 벡터 +
  RoPE(1D 고정). 위 K₊, K₋가 이 갱신의 시차 커널이다.
- **규칙 헤드:** φ = unit(W_φ h)(출력 칸), 그룹 안 다른 시범의 leave-one-out 통계 G = Σφφᵀ/n, S = Σ onehot(y)φᵀ/n,
  블록마다 θ ← soft(θ − (θG − S), λ), r = θφ + Σ_k Γ_k κ_k, 지각으로 W_fb r 피드백. Γ는 프레임 K개(학습된 행·열 주파수의 softmax
  위치 읽기)에 대한 같은 lasso.
- **정리 0(이전 레포 `docs/claude_2026-10-21_minimal_rule_synapse.md`):** S(가설 족 안), L(G 좌표에서 성김), I(시범 측정의 영공간
  성질), C(수렴, λ → 0⁺)이면 lasso 최소해가 참 규칙이고 질의 답이 정확하다. 원환 토이는 S, L, I를 구조로 만족시킨 경우다.
  ARC에서는 S, L이 학습에 걸린다. ARC-2 실패는 S 위반으로 해석된다.
- **λ 사전값:** κ/√n(κ = 0.145, n = 시범 라벨 칸). ARC-2 eval 질의 중앙값 0.0052, 0.005는 그 0.97배(10~90%: 0.53~1.37배).
  ≤10에서 학습된 λ는 이론값의 약 0.5배(0.0057 대 0.011).
