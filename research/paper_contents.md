## 2. 정리 수준에서 증명되는 명제

중심은 "k, v가 블록마다 변하는 값이고 두 흔적에 비대칭 창이 걸릴 때, 쓰기가 STDP의 시냅스 적분과 정확히 같다"는 것이다(T1~T3).
근거 문서: 이전 레포 `docs/claude_2026-10-17_time_dependent_plasticity.md`(2.3, 2.5, 2.7절), `docs/claude_2026-10-18_handoff.md`(1.1절),
`docs/claude_essential_properties.md`(C5). 이전 레포 `tests/test_bands.py`가 FP64로 검사했고, 10-30에 독립 구현으로 다시 확인했다
(R = 4 복소 극점, 30블록, 온라인 대 쌍 이중합 최대 차 3.9e−14).

| # | 명제 | 상태 | 근거 / 할 일 | 위치 |
|---|---|---|---|---|
| T1 | **흔적 = 쌍 기반 STDP 적분.** pre = k(t), post = v(t)(같은 칸, 블록 t의 부호 있는 연속값). pre 흔적 E_K,r(t) = Σ_{s≤t} γ_r z_r^{t−s} k(s), post 흔적 D_V,r(t) = Σ_{s<t} γ_r z_r^{t−s} v(s)로 쓴 블록 쓰기 S(t) = Σ_r Re(a_r v(t)E_K,r(t)ᵀ + b_r D_V,r(t)k(t)ᵀ)를 T까지 더하면, 양쪽 사건이 모두 T 이전인 모든 (post, pre) 쌍의 합 Σ L(t_post − t_pre)·v(t_post)k(t_pre)ᵀ와 같다. 창은 L(Δ) = Σ_r γ_r Re(a_r z_r^Δ)(Δ ≥ 0, pre가 앞섬), Σ_r γ_r Re(b_r z_r^{\|Δ\|})(Δ < 0, post가 앞섬). 각 쌍은 나중 사건이 오는 블록에서 정확히 한 번 더해진다: pre가 앞선 쌍은 post가 올 때 pre 흔적으로, post가 앞선 쌍은 pre가 올 때 post 흔적으로 | 근거 있음 | 증명: 흔적의 선형 점화식을 펼치고 합의 순서를 바꾼다. 스파이크 STDP의 표준 흔적 구현(pre 스파이크에 pre 흔적, post 스파이크에 post 흔적)과 같은 구조 | 본문(중심) |
| T2 | **창은 활동의 시차 상관만 본다(스파이크가 필요 없는 이유).** Σ_t S(t) = Σ_Δ L(Δ)·C(Δ), C(Δ) = Σ_t v(t)k(t−Δ)ᵀ. 발화율 STDP의 학습 방정식 ∫W(s)⟨post(t)pre(t−s)⟩ds(Kempter 형태)가 기댓값이 아니라 정확히 성립한다. 활동은 정상 수준으로부터의 부호 있는 편차로 정의한다(Scarpetta, Zhaoping & Hertz 2002). 스파이크는 이 상관을 통해서만 들어가므로, 결정론적 재귀에서는 따로 정보를 지니지 않는다 | 근거 있음 | 이전 레포 10-17 문서 2.1, 2.3, 2.5절. Scarpetta 2002 서지 확인 | 본문 |
| T3 | **재귀가 선후를 저절로 준다.** 홀수 창은 상관의 홀수부 C_odd(Δ) = ½[C(Δ) − C(−Δ)]만 본다. 선형화 h_{t+1} = A h_t에서 C_odd(s) = ½ W_v[A^sΣ − Σ(A^s)ᵀ]W_kᵀ이고, 0이 되는 것은 시간 가역적인 경우와 고정점뿐이다. 비대칭 창이 재귀 위에서 읽을 것이 있다는 뜻이다(적분의 이득 자체는 별개 질문) | 확인 필요 | 이전 레포 10-17 문서 2.7절의 유도를 다시 따라가 검산 | 본문 또는 부록 |
| T4 | **창의 족과 유계성.** 한쪽마다 감쇠 복소 지수 R개의 합. 표준 지수 쌍 STDP(R = 1, θ = 0, a > 0, b < 0)가 특수한 경우다. γ_r = √(1−\|z_r\|²)로 흔적이 유계다 | 근거 있음 | `arc/model.py`, 이전 레포 10-18 인수인계 1.1절. 극점 매개화는 LRU식의 변형 | 방법 또는 부록 |
| T5 | **통합과 망각.** W(T) = Σ_t η(1−η)^{T−t} S(t)이므로 쌍마다 창(시차) × 망각(나중 사건의 나이)이 곱해진다. band_product는 대역마다 망각률 1 − \|z_r\|²인 같은 형태 | 근거 있음 | 이전 레포 10-17 문서 2.3절(시차와 나이의 두 축), `claude_2026-10-20_band_product_hebb.md` | 부록 |
| T6 | **따름: Hebb 항 = 창의 순넓이.** 고정점에서 모든 쌍이 같은 곱이므로 기억은 창의 넓이 × v kᵀ다. 천천히 변하면 0차가 넓이, 1차가 창의 1차 모멘트 × 미분 항(Kempter의 직류 항과 같은 구조) | 근거 있음 | 이전 레포 10-17 문서 2.5절 | 본문(한 줄) 또는 부록 |
